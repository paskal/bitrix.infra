# Куда уходят алерты Zabbix

Действия и способы доставки **не выгружаются** через `configuration.export` — он умеет только
шаблоны, хосты, карты и media types. Поэтому маршрутизация существует лишь в живом Zabbix, и
этот файл единственное место, где её можно прочитать, не открывая интерфейс.

Доставка одна на всё: media type **16 Telegram**. Все остальные выключены.

## Правило

Действие выбирается **по шаблону**, с которого пришла проблема. Каждый канал это отдельное
действие с условием «группа хостов Favor-group И шаблон X», а общий tech-чат забирает всё
остальное и перечисляет исключения явным списком.

| Шаблон | Действие | Куда уходит |
|---|---|---|
| Favor-group ads monitoring (10371) | [9] ads problems reporting | чат рекламы `-4246484235` |
| Favor-group goods monitoring (10367) | [10] goods problems reporting | чат товаров `-4237395691` |
| Favor-group content monitoring (10369) | [11] content problems reporting | чат контента `-4272557093` |
| Favor-group ASR monitoring (10658) | [12] Favor group deep tech | Dmitry лично `107408628` |
| Favor-group tg-agent monitoring (10657) | [12] Favor group deep tech | Dmitry лично `107408628` |
| Linux by Zabbix agent (10284), MySQL agent 2 (10635) | [12] Favor group deep tech | Dmitry лично `107408628` |
| всё прочее в группе Favor-group | [7] tech chat problems reporting | общий tech-чат `-1001455514139` |

Общий tech-чат **делится с Евгением и предназначен только для проблем PHP и сайта**. Всё, что
относится к нашей собственной автоматике — расшифровки звонков, остаток DeepSeek, обогащение
лидов, рекламный крон, — идёт лично Дмитрию.

## Как подключить новый шаблон

**Сначала ищи готовое действие с нужным адресатом и добавляй шаблон в него.** Новых действий
заводить не нужно: их и так восемь, а каждое лишнее это ещё одно место, где маршрут может
разойтись с ожиданиями. Действие [12] собрано под условие `A and (B or C or …)`, поэтому шаблон
добавляется одним условием и ничего не ломает.

Затем **обязательно добавь тот же шаблон исключением в действие [7]**, иначе события уйдут ещё и
в общий чат. Порядок именно такой: сначала адресат, потом исключение, иначе между шагами будет
окно, в котором алерты видит Евгений.

## Чего здесь сознательно нет

Метка `notify=admin` (действие [13]) существует для 5xx-алертов сайта и уводит их Дмитрию поверх
обычной маршрутизации. Вешать её на триггеры вместо маршрута по шаблону не следует: метку легко
забыть на новом триггере, и тогда он молча уедет в общий чат, а если шаблон при этом уже указан
в каком-то действии, сообщение придёт дважды.

## Как это читать, не заходя в Zabbix

`configuration.export` действия не отдаёт (только шаблоны, хосты, карты и media types), но
`action.get` их читает. Живое состояние:

```
python3 -c "
import os
from zabbix_utils import ZabbixAPI
api=ZabbixAPI(url=os.environ['ZABBIX_URL']); api.login(token=os.environ['ZABBIX_TOKEN'])
for a in api.action.get(output='extend', selectFilter='extend', selectOperations='extend', filter={'eventsource':0}):
    print(a['actionid'], a['name'], a['filter']['eval_formula'])
"
```

Проверять доставку лучше по факту, а не по конфигу: сообщения бота `@dmitry_monit_bot` видны и в
личке, и в общем чате, так что всегда можно посмотреть, куда алерт ушёл на самом деле.
